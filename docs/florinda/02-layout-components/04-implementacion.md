# Implementación — Issue 02

## Fase 1 — Diseño

1. Definir tokens visuales: colores, spacing, tipografía y breakpoints.
2. Identificar contenido configurable por props/slots.
3. Definir comportamiento de menú, modal y navegación móvil.

## Fase 2 — Componentes

1. Crear Layout/Header/Sidebar/Footer.
2. Crear Card y Modal sin dependencias de datos.
3. Usar semantic HTML, labels y estados de foco.
4. Enlazar Privacy/Terms desde Footer.

## Fase 3 — Verificación

1. Montar componentes con datos de ejemplo locales.
2. Probar props, slots, eventos, cierre de modal y menú móvil.
3. Probar Public/Admin/Client en distintos tamaños.
4. Confirmar que no importan services/stores.

## Criterio de entrega

Añadir ejemplos mínimos de uso en una vista o documentación del componente. Si un componente solo funciona con datos hardcodeados o una ruta concreta, todavía no cumple la finalidad de esta issue.
