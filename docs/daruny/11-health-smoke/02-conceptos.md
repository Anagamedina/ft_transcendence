# Conceptos — Issue 11

Liveness — proceso vivo, 15 min; readiness — dependencias listas, 15 min; healthcheck — comando con código 0/!=0, 20 min; smoke test — recorrido mínimo, 20 min; timeout/reintento — 20 min; observabilidad básica — 20 min.

Un contenedor “running” no necesariamente está listo. El smoke test debe ser pequeño, repetible y no depender de datos manuales.
