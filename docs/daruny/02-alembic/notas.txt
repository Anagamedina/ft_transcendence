



Sqlalchemy define como deberiamos tener la base de datos.
Alembic registra y aplica los cambios necesarios para actualizar
PostgresSQL hasta ese tener todo actualizado

alembic revision ...
        ↓
se crea una migración

alembic upgrade head
        ↓
PostgreSQL aplica el cambio

alembic downgrade -1
        ↓
PostgreSQL revierte el cambio


En backend/alembic.ini  es el archivo de config de alembic
el cual nos indica:
- donde estan las migraciones
- como encontrar el codigo python del proyecto
- que configuracion de logs usar.
- que URL de base de datos debe utlizar.


en ALEMBIC.INI configuramos la ubicación y el
comportamiento general de Alembic

en env.py conecta Alembic con la configuracion real,
la base de datos y los modeles SQLAlchemy

credentials are not stored in alembic.ini.


2 funciones importantes en env.py

def run_migrations_offline() -> None:
- genera una SQL sin abri una conexion directa a postgreSQL

def run_migrations_online() -> None:
- Connects to PostgreSQL to execute the migration.
